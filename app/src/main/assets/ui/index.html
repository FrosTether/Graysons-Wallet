          About this proof of concept

          Quantum-safe signatures. Every transaction is signed with LMS (RFC 8554, NIST SP 800-208), a hash-based scheme. Shor's algorithm breaks the elliptic curves under Monero and Wownero; it doesn't apply to SHA-256. Each key has 1,024 one-time signatures. The chain makes sure none is ever used twice, and the wallet rotates to a new key before they run out.

          Not private. Balances and transfers are public, like Bitcoin. CryptoNote's ring signatures and stealth addresses use elliptic curves, and no practical quantum-safe replacement exists yet.

          Tone-gated mining. Frostoise mines only while the phone hears one of three tones: 4.0 Hz (delta), 7.83 Hz (theta, the Schumann resonance) or 11.11 Hz (alpha). The tone sets how hard it mines: low, medium or high. Each block records the reading. Other nodes can check that the reading is plausible, but they can't prove a physical resonator was there: a synthesized tone looks the same.
