Build from source

  1. Get the code.The node, the chain rules and the Android app live in one repository. 
    git clone https://github.com/FrosTether/Graysons-Wallet.git
cd Graysons-Wallet
  2. Run the chain tests.They cover consensus, signatures, sync, reorgs and the wallet. ConsensusTest fails if a change would alter the chain ID, so you can't fork the network by accident. 
    ./gradlew :core:test
  3. Build frostnode.This makes node/build/install/frostnode/ with bin/frostnode and its lib/. The same folder, zipped, is frostnode.zip on each release. 
    ./gradlew :node:installDist

A network on one machine

Two nodes on different ports, the second syncing from the first. Each keeps its own data folder, so you can stop, wipe and restart either one.

# node A, with FrostExplorer on 7831
node/build/install/frostnode/bin/frostnode --data a --port 7830 --explorer-port 7831

# node B, in a second terminal, peered with A, no explorer
node/build/install/frostnode/bin/frostnode --data b --port 7840 --explorer-port 0 --peer 127.0.0.1:7830

Mining happens on phones, so blocks come from Graysons Vault phones pointed at your node (Node → Add, your machine's local IP). Phones on the same Wi-Fi also find nodes on their own over UDP 7830.

Options and files

frostnode [--data DIR] [--port 7830] [--explorer-port 7831] [--peer HOST[:PORT]]...
--peer
A node to sync from at startup. Repeat it for more. A node remembers up to 64 peers.
--explorer-port 0
Turns FrostExplorer off.
chain.jsonl
Every block, one JSON object a line, in the data folder. It's re-checked from genesis at startup, and a bad line is cut off along with everything after it.
peers.json, settings.json
The peers it knows and its settings, next to the chain.
Logs
The first line shows the chain ID. Every 5 minutes it logs the height, the peers it reached and the mempool size.

The node's HTTP API

Nodes talk plain HTTP and JSON on port 7830. These are the same calls phones and other nodes use, so you can sync, watch or submit from any language.

CallReturns
GET /p2p/infoChain ID, height, tip hash, total work, next difficulty, agent, mempool size, QNR mined. Also at /api/status.
GET /p2p/hashes?from=H&count=NBlock hashes from height H, up to 2,000.
GET /p2p/blocks?from=H&count=NFull blocks from height H, up to 50 or about 3 MB.
POST /p2p/blockSubmit a block as JSON. {"ok":true} or a 400 with the reason.
POST /p2p/txSubmit a signed transaction. Returns its txid.
GET /p2p/mempoolUp to 200 waiting transactions.
GET /p2p/peersThe peers this node has reached.
POST /p2p/hello{"port":7830} asks the node to add you as a peer.
GET /api/resolve?addr=XAn address or .frostchain name, resolved to the account ID, raw address and name.
GET /api/account?addr=XBalance, mining rewards still locked, payments waiting to go out, and name.
GET /api/history?addr=XEvery payment, reward and name claim for an account.
GET /api/block?h=HOne block with its hash. No h gives the tip.
 
curl http://localhost:7830/p2p/info
curl "http://localhost:7830/api/resolve?addr=jacobfrost"

Send X-Frost-Port: 7840 with a POST and the node adds you as a peer at that port. FrostExplorer's read-only API on port 7831 (status, blocks, search, CORS open) is listed in the node guide.

The rules a node checks

Blocks
Double SHA-256 over a 152-byte header. One every 5 minutes on average, never within 270 seconds of the last, at most 30 seconds ahead of a node's clock. LWMA difficulty over 60 blocks.
Reward
13.37 QNR a block in the first year, then 4.25% less each year, down to a tail of 1.337 QNR a block forever from year 55. No cap. Mined coins unlock after 12 blocks.
Tone proof
Every block carries the reading of the tone it was mined on: 3.75–4.25, 7.50–8.20 or 10.80–11.40 Hz, peak at least 10 times the noise, at most 15 minutes old.
Signatures
LMS (RFC 8554), 1,024 one-time signatures per key, with key rotation on chain.
Where
Consensus.java and Chain.java in the chain core.

Running a public node

  • InstallOne command on Ubuntu or Debian sets up Java, the service and the firewall. Run it again to update.
  • Put the explorer onlineA Cloudflare Tunnel gives FrostExplorer an https address with no port to open.
Ports
Open TCP 7830 for peers and phones. Keep 7831 closed and use a tunnel instead.
Keys
A node holds no wallet and no 25 words, so there's nothing to steal on the server.
Backups
Optional: any node can re-sync the chain from its peers. Copying chain.jsonl just makes a restart faster.
Updates
Watch the releases. A new chain ID means a rule change, and every node has to update to follow it.
