Run a node

Phones mine Qoin, but phones sleep. An always-on node keeps the chain online: it stores every block, passes new blocks and payments between phones, and shows the chain live in FrostExplorer.

Download frostnode The full guide

Needs Java 17. It starts in about 100 MB of memory, and the chain grows by about 130 MB a year. It never holds anyone's 25 words.

What a node does

Keeps the chain
Stores every block and checks every rule, the same checks the phones run.
Relays
Passes new blocks and payments between phones that can't reach each other, on TCP port 7830.
Shows it
Serves FrostExplorer on port 7831: every block, its tone, names and balances, updating live.
No wallet
A node can't spend, mine or see anyone's 25 words. Mining still happens on phones that hear a tone.
Rewards
None yet. Paying always-on nodes, the way Dash pays its masternodes, is one of the governance options I'm working out. For now, running one is how you keep the network up.

Pick where it runs

Anything that stays on and online works. A free cloud server is best, since it never sleeps and has a fixed address.

  1. Get a server.Oracle Cloud's Always Free tier gives you a small Ubuntu machine at no cost. Any Ubuntu or Debian server works.
  2. Run the installer.It installs Java and the latest frostnode, checks the download against the release checksums, and sets it up as a service that starts on boot. Run it again any time to update. 
    curl -fsSL https://get.finux.tech/node/install.sh | sudo sh
  3. Open port 7830.The installer opens it on the server itself. Cloud providers block it a second time outside the machine: on Oracle Cloud, go to Networking, your VCN, Security lists, Default, and add an ingress rule for source 0.0.0.0/0, TCP, port 7830.
  4. Check it.From your phone's browser, open http://<server IP>:7830/p2p/info. It should show the chain b8b1ec3fefb96834 and the height.
  1. Install Java 17.On Windows or a Mac, use the Temurin 17 installer from adoptium.net. On Linux, sudo apt install openjdk-17-jre-headless.
  2. Download and unzip frostnode.Unzip frostnode.zip anywhere you like.
  3. Start it.Open a terminal in that folder and run: 
    # Mac or Linux
frostnode/bin/frostnode --data frostnode-data
# Windows
frostnode\bin\frostnode.bat --data frostnode-data
  4. Keep it awake.Set the laptop to never sleep while it's plugged in. Phones on the same Wi-Fi can add it by the laptop's local IP. For phones elsewhere, your router has to forward TCP 7830 to the laptop.
  1. Install Termux.Get it from F-Droid. A spare phone on a charger makes a decent node.
  2. Run frostnode next to the app.Graysons Vault already uses port 7830 on the phone, so frostnode takes 7832 and 7833 and copies the chain from the app: 
    pkg install openjdk-17 unzip
curl -LO https://github.com/FrosTether/Graysons-Wallet/releases/latest/download/frostnode.zip
unzip -o frostnode.zip
termux-wake-lock
frostnode/bin/frostnode --data ~/frostnode-data --port 7832 --explorer-port 7833 --peer 127.0.0.1:7830
  3. Open the explorer.Visit http://localhost:7833 in the phone's browser. It runs while the phone stays awake.

Connect the phones

  1. Open Graysons Vault.Go to Node, then Add.
  2. Enter the node's address.The server's IP or a name like node.finux.tech pointing at it. Port 7830 is the default, so the host alone works.
  3. Watch it sync.The Node screen shows the node's height. Phones now pass blocks through it, even when they're on different networks.

Put FrostExplorer on the web

A Cloudflare Tunnel gives the explorer an https address on your own domain, with no port to open. It runs on the same machine as the node.

# try it: prints a temporary https://….trycloudflare.com address
cloudflared tunnel --url http://localhost:7831

# keep it, on your own name
cloudflared tunnel login
cloudflared tunnel create frostexplorer
cloudflared tunnel route dns frostexplorer explorer.finux.tech
cloudflared tunnel run --url http://localhost:7831 frostexplorer

Get cloudflared from Cloudflare's downloads page, or pkg install cloudflared in Termux. Keeping it running after a reboot is in the full guide.
